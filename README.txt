Модуль данных О!дин запрос версия 1.0.0

Начните с README.md. Команда демо:
  .venv\Scripts\python.exe -m travel_data demo

Запуск двойным щелчком:
  INSTALL.cmd — установка на другом компьютере.
  START.cmd — меню запуска демо, настроек и тестов.
  OPEN_CODE.cmd — открыть исходники в Visual Studio Code.

Реальные источники:
  Получите свои ключи у поставщиков по ссылкам из README.md.
  START.cmd → 5: скрытый ввод ключей в локальный .env.
  START.cmd → 6: импорт настоящего справочника Яндекс Расписаний.
  START.cmd → 7: реальные запросы и отчёт reports/live-check.json.
  В чат и публичный GitHub ключи не отправлять.

Четыре функции: search_hotels, search_transport, get_weather, get_route.
Все показанные поля обязательны, additionalProperties=false.
Неизвестное значение null допустимо только там, где разрешено схемой.
request_id и schema_version создаёт backend, модель передаёт arguments.
tools.json использует нейтральный input_schema и требует адаптации к SDK модели.

Деньги: целые копейки, только RUB; цена на всю группу и весь запрошенный срок.
Дата: YYYY-MM-DD. Время: ISO 8601 с UTC offset.
Погода: начало включено, конец исключён; максимум 16 дней, без выдуманного прогноза.
Дорога: метры и секунды, максимум один автомобильный маршрут.
Транспорт: одна сторона; обратная запрашивается отдельно.
Отели и транспорт: limit 1..5; returned_count = len(data.items).
Нарушения обязательных условий исключаются; unknown требует подтверждения.
Ошибка отличается от отсутствия результатов. При error items=[], error заполнен.
Fixtures вымышленные, включаются только явно, is_fixture=true.
Нельзя подменять live-ошибки фиктивными предложениями.
Примеры проверяются с фиксированным временем 2026-10-23T12:00:00Z.

Общий лимит функции 15 секунд, максимум один повтор временного сбоя,
не более двух обращений к одному хосту одновременно в процессе.
При нескольких процессах общий лимитер реализует backend.
Кеш по умолчанию выключен; разрешение поставщика обязательно.
Секреты задаются локально через .env либо переменные окружения.

Ограничения поставки:
  Реальными запросами 24.10.2026 проверены Расписания, Погода и 2ГИС.
  Ключи находятся только в локальном .env, в GitHub их нет.
  На другом компьютере нужно настроить свои доступы и импортировать города.
  Тестовый ключ Погоды действует до 01.11.2026, 2ГИС — до 24.11.2026.
  Партнёрский доступ к отелям Островка ещё не получен.
  Полный архив контрактов из DOCX отсутствует. JSON Schema восстановлены
  по документу и требуют сверки с оригиналом/согласования с потребителями.
